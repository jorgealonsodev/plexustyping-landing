First public version.

### Highlights

- Adaptive practice that focuses on your weak keys, with a local corpus (Spanish, English, Brazilian Portuguese, French and German), “Palabras” (words) and “Código” (code) modes, and optional AI texts (Claude, OpenAI, Gemini, OpenCode Go or your ChatGPT plan).
- A metronome with adaptive tempo and a quick panel, ghost session, progressive unlock, daily goal, history charts and profiles.
- Accessibility: every theme meets WCAG AA, two high-contrast themes, full keyboard navigation, screen reader announcements, adjustable font size, letter spacing and line height, a color-blind keyboard and reduced motion.
- Personalization: bundled practice fonts, cursor styles, dimmed pending text, VS Code theme import and a reorganized settings window with quick search.
- Settings are saved in the app's local database and survive restarts.

### Files

- `plexustyping_0.1.0_amd64.deb`: Debian and Ubuntu, `sudo apt install ./plexustyping_0.1.0_amd64.deb` (the package is called `plexus-typing`).
- `plexustyping-0.1.0-linux-x86_64.tar.gz`: any Linux with WebKitGTK 4.1; unpack it and run `./install.sh` (installs into `~/.local`; `--uninstall` removes it).
- `PlexusTyping_0.1.0_x64-setup.exe`: Windows 10 and 11, per-user install. **Unsigned**: SmartScreen warns; choose “More info” → “Run anyway”.
- `SHA256SUMS`: sums of the three files; check them with `sha256sum -c SHA256SUMS`.
