The interface in five languages, an unlimited practice mode and a new caret.

### What's new

- **Interface languages:** Español, English, Português (Brasil), Français and Deutsch. On first start it follows the computer's language, and English when that one is not supported. Change it in “Settings → Appearance → Interface language”, separately from the practice-text language.
- **Text length from the header:** a picker next to Prose / Words / Code chooses the text length, or the maximum lines in code mode.
- **More lengths and an unlimited mode:** texts of up to 2000 characters (800, 1000, 1500 and 2000 join the earlier lengths) and “Unlimited”, a text that grows while you type, with AI continuations or, when the AI is slow or fails, texts from the local corpus. <kbd>Esc</kbd> or “End” scores what you typed.
- **Caret bar:** a thin bar between characters, Monkeytype-style, that blinks while you are not typing; it is now the default cursor. The bar and the underline have square corners.
- **Settings search:** <kbd>Esc</kbd> clears an active search from anywhere in the window, and the arrow keys on the section tabs end it.

### Fixes

- “Repeat” after an unlimited text repeats only the part you typed.
- Linux: the desktop entry escapes a `%` in the path, `install.sh` fails with a notice when it cannot write its file list, and the `.tar.gz` launcher only counts the 64-bit WebKitGTK as installed.

### Files

- `plexustyping_0.2.0_amd64.deb`: Debian and Ubuntu, `sudo apt install ./plexustyping_0.2.0_amd64.deb` (the package is called `plexus-typing`).
- `plexustyping-0.2.0-linux-x86_64.tar.gz`: any Linux with WebKitGTK 4.1; unpack it and run `./install.sh` (installs into `~/.local`; `--uninstall` removes it).
- `PlexusTyping_0.2.0_x64-setup.exe`: Windows 10 and 11, per-user install. **Unsigned**: SmartScreen warns; choose “More info” → “Run anyway”.
- `SHA256SUMS`: sums of the three files; check them with `sha256sum -c SHA256SUMS`.
