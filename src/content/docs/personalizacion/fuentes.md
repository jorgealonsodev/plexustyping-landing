«Ajustes → Texto → Fuente» cambia el tipo de letra del texto de práctica, tanto en prosa como en código; el resto de la interfaz no cambia. Además de «Predeterminada», hay diez fuentes incluidas en la aplicación, así que ninguna se descarga de internet. Cada opción se muestra en su propia fuente.

## Fuentes disponibles

| Grupo | Fuente | Descripción en la app |
|---|---|---|
| Mecanografía | Predeterminada | La fuente de siempre de PlexusTyping (JetBrains Mono) |
| Mecanografía | Roboto Mono | La fuente por defecto de Monkeytype |
| Mecanografía | JetBrains Mono | Monoespaciada de programación con letras altas y claras |
| Mecanografía | Fira Code | Monoespaciada de programación; sin ligaduras, cada carácter se ve por separado |
| Mecanografía | Source Code Pro | Monoespaciada de Adobe, sobria y abierta |
| Mecanografía | IBM Plex Mono | Monoespaciada de IBM con remates suaves |
| Mecanografía | Inconsolata | Monoespaciada compacta y clásica |
| Legibilidad | Atkinson Hyperlegible Mono | Del Braille Institute, pensada para personas con baja visión |
| Legibilidad | Intel One Mono | Diseñada con desarrolladores con baja visión o ciegos |
| Legibilidad | Lexend Deca | Proporcional, de la investigación sobre fluidez lectora |
| Legibilidad | OpenDyslexic | Letras con la base más gruesa; proporcional |

Lexend Deca y OpenDyslexic son proporcionales: cada letra ocupa un ancho distinto. Las demás son monoespaciadas.

## Probar una fuente

Debajo del selector hay un campo «Prueba la fuente» donde puedes escribir para ver cómo queda antes de practicar.
