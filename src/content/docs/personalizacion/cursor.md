El cursor marca el siguiente carácter que tienes que escribir. En «Ajustes → Texto → Cursor» puedes elegir entre cinco estilos: «Barra», el estilo por defecto, una línea fina entre caracteres como la de Monkeytype; «Resaltado», «Bloque», «Subrayado» y «Contorno». Sobre un carácter fallado, el cursor toma el color de error. El parpadeo se controla aparte, con «Cursor parpadeante».

## Estilos

| Estilo | Cómo se ve |
|---|---|
| Barra (por defecto) | Una línea vertical fina, de esquinas rectas, en el borde izquierdo del carácter |
| Resaltado | El carácter se tiñe y se subraya |
| Bloque | Un bloque de color con el carácter en el color del fondo |
| Subrayado | Una línea de esquinas rectas bajo el carácter |
| Contorno | Un recuadro alrededor del carácter |

La barra pasó a ser el cursor por defecto en la versión 0.2.0; antes lo era «Resaltado». Si ya habías elegido un estilo, la app lo conserva.

## Cursor parpadeante

«Cursor parpadeante» está activado por defecto: el cursor parpadea mientras esperas y se queda fijo mientras escribes. Puedes desactivarlo en «Ajustes → Texto». El cursor no parpadea si el sistema tiene activado el movimiento reducido: consulta [Movimiento reducido](/docs/accesibilidad/movimiento-reducido).
