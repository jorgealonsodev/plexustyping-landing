El cursor marca el siguiente carácter que tienes que escribir. En «Ajustes → Texto → Cursor» puedes elegir entre cinco estilos: «Resaltado», que es el estilo por defecto, «Barra», «Bloque», «Subrayado» y «Contorno». Sobre un carácter fallado, el cursor toma el color de error. El parpadeo se activa aparte, con «Cursor parpadeante».

## Estilos

| Estilo | Cómo se ve |
|---|---|
| Resaltado (por defecto) | El carácter se tiñe y se subraya |
| Barra | Una línea vertical en el borde izquierdo del carácter |
| Bloque | Un bloque de color con el carácter en el color del fondo |
| Subrayado | Una línea bajo el carácter |
| Contorno | Un recuadro alrededor del carácter |

## Cursor parpadeante

«Cursor parpadeante» está desactivado por defecto. Aunque lo actives, el cursor no parpadea si el sistema tiene activado el movimiento reducido: consulta [Movimiento reducido](/docs/accesibilidad/movimiento-reducido).

## Próxima versión (0.1.1)

En la próxima versión, «Barra» pasa a ser el estilo por defecto, con el aspecto del cursor de Monkeytype, y el parpadeo viene activado: parpadea mientras esperas y queda fijo mientras escribes. Hasta que se publique, la versión 0.1.0 funciona como se describe arriba.
