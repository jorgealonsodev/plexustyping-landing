Settings → Text → “Fuente” (font) changes the typeface of the practice text, in both prose and code; the rest of the interface does not change. Besides “Predeterminada” (default), there are ten fonts bundled with the application, so none is downloaded from the internet. Each option is shown in its own font.

## Available fonts

| Group | Font | Description in the app (translated) |
|---|---|---|
| Typing | Predeterminada (default) | PlexusTyping's usual font (JetBrains Mono) |
| Typing | Roboto Mono | Monkeytype's default font |
| Typing | JetBrains Mono | A programming monospace with tall, clear letters |
| Typing | Fira Code | A programming monospace; without ligatures, every character stands alone |
| Typing | Source Code Pro | Adobe's monospace, sober and open |
| Typing | IBM Plex Mono | IBM's monospace with soft serifs |
| Typing | Inconsolata | A compact, classic monospace |
| Legibility | Atkinson Hyperlegible Mono | From the Braille Institute, designed for people with low vision |
| Legibility | Intel One Mono | Designed with low-vision and blind developers |
| Legibility | Lexend Deca | Proportional, from research on reading fluency |
| Legibility | OpenDyslexic | Letters with a heavier base; proportional |

The groups are “Mecanografía” (typing) and “Legibilidad” (legibility) in the app. Lexend Deca and OpenDyslexic are proportional: each letter takes a different width. The others are monospaced.

## Trying a font

Below the selector there is a “Prueba la fuente” (try the font) field where you can type to see how it looks before practicing.
