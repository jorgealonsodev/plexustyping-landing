The cursor marks the next character you have to type. In Settings → Text → “Cursor” you can choose among five styles: “Resaltado” (highlight), the default style, “Barra” (bar), “Bloque” (block), “Subrayado” (underline) and “Contorno” (outline). On a missed character, the cursor takes the error color. Blinking is turned on separately, with “Cursor parpadeante” (blinking cursor).

## Styles

| Style | How it looks |
|---|---|
| Resaltado (highlight, default) | The character is tinted and underlined |
| Barra (bar) | A vertical line on the character's left edge |
| Bloque (block) | A color block with the character in the background color |
| Subrayado (underline) | A line under the character |
| Contorno (outline) | A box around the character |

## Blinking cursor

“Cursor parpadeante” is off by default. Even if you turn it on, the cursor does not blink if the system has reduced motion on: see [reduced motion](/en/docs/accessibility/reduced-motion).

## Next version (0.1.1)

In the next version, “Barra” (bar) becomes the default style, with the look of Monkeytype's cursor, and blinking comes on: it blinks while you wait and stays still while you type. Until it is released, version 0.1.0 works as described above.
