The cursor marks the next character you have to type. In Settings → Text → “Cursor” you can choose among five styles: “Bar”, the default style, a thin line between characters like Monkeytype's; “Highlight”, “Block”, “Underline” and “Outline”. On a missed character, the cursor takes the error color. Blinking is controlled separately, with “Blinking cursor”.

## Styles

| Style | How it looks |
|---|---|
| Bar (default) | A thin vertical line with square corners on the character's left edge |
| Highlight | The character is tinted and underlined |
| Block | A color block with the character in the background color |
| Underline | A line with square corners under the character |
| Outline | A box around the character |

The bar became the default cursor in version 0.2.0; before, it was “Highlight”. If you had already chosen a style, the app keeps it.

## Blinking cursor

“Blinking cursor” is on by default: the cursor blinks while you wait and stays still while you type. You can turn it off in Settings → Text. The cursor does not blink if the system has reduced motion on: see [reduced motion](/en/docs/accessibility/reduced-motion).
