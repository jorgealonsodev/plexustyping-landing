In Settings → Text you can adjust three values of the practice text, in prose and in code: “Tamaño de letra” (font size), “Espaciado entre letras” (letter spacing) and “Interlineado” (line height). Each has a slider and a number field, applies at once and is saved. A value outside its range is clamped to the nearest limit.

## Values

| Setting | Range | Step | Default |
|---|---|---|---|
| Font size | 80–200 % | 10 % | 100 % |
| Letter spacing | 0–0.30 em | 0.02 em | 0 em |
| Line height | 1.2–2.4 | 0.1 | 1.75 |

These settings only affect the text you type. The hint under each setting shows the current value and its range, for example “Texto de práctica: 100 % (de 80 % a 200 %).” (practice text: 100 %, from 80 % to 200 %).

## Combining with a legibility font

Typography combines with the chosen font. The “Legibilidad” (legibility) group in [fonts](/en/docs/personalization/fonts) includes Atkinson Hyperlegible Mono, Intel One Mono, Lexend Deca and OpenDyslexic.
