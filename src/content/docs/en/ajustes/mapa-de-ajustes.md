The “Settings” window opens with `Ctrl+,` or with the gear button in the header. It has nine sections, in this order: Practice, Text, Keyboard, Metronome, Code, Appearance, Accessibility, AI and Profiles. Every change is saved at once and remembered after a restart. To find a setting by name, use the search box at the top.

## Practice

| Setting | Options | Default |
|---|---|---|
| “Text language” | Español, English, Português (Brasil), Français, Deutsch | Español |
| “Error mode” | “Allow continuing”, “Stop until corrected”, “Erase with Backspace” | “Allow continuing” |
| “Targets” | 2 or 3 weak units per text | 2 |
| “Length” | 100, 200, 300, 450, 600, 800, 1000, 1500 or 2000 characters, or Unlimited | 300 |
| “Live stats” | On or off | On |
| “Ghost session” | On or off | On |
| “Progressive unlock” | On or off, per profile | Off |
| “Target speed” | 20, 30, 40 or 50 WPM | 30 WPM |

More in [error modes](/en/docs/practice/error-modes), [ghost session](/en/docs/practice/ghost-session) and [progressive unlock](/en/docs/practice/progressive-unlock). The length is also chosen in the header, next to Prose / Words / Code: see [length and unlimited text](/en/docs/practice/length-and-unlimited-text).

## Text

“Font”, “Font size”, “Letter spacing”, “Line height”, “Cursor”, “Blinking cursor” and “Dim pending text”. See [fonts](/en/docs/personalization/fonts), [typography](/en/docs/personalization/typography), [cursor](/en/docs/personalization/cursor) and [dimmed pending text](/en/docs/personalization/dimmed-pending-text).

## Keyboard

| Setting | Default |
|---|---|
| “Layout” (8 layouts) | Español (España) |
| “On-screen keyboard” (`F2`) | On |
| “Flashes” | On |
| “Heatmap” | Off |

See [layouts](/en/docs/keyboard-and-languages/layouts) and [on-screen keyboard and flashes](/en/docs/keyboard-and-languages/on-screen-keyboard-and-flashes).

## Metronome

| Setting | Range or options | Default |
|---|---|---|
| “Metronome” (`F4`) | On or off | Off |
| “Tempo” | 30–300 BPM | 60 BPM |
| “Adaptive tempo” | On or off | Off |
| “Sound” | “Click”, “Wood”, “Beep” | “Click” |
| “Volume” | 0–100% | 80% |
| “Accent” | Every 0–16 beats (0 = no accent) | Every 4 |

See [metronome basics](/en/docs/metronome/basics).

## Code

“Language” picks one of code mode's 15 languages; in code mode it is also chosen in the header.

| Setting | Options | Default |
|---|---|---|
| “Indentation” | “Automatic on Enter”, “Manual” | Automatic on Enter |
| “Maximum lines” | 5–20 | 12 |

## Appearance

“Theme”, with the 59 bundled themes and the imported ones, “Import VS Code theme…” and “Interface language”: Español, English, Português (Brasil), Français or Deutsch, or “Automatic (system language: …)”, which follows the computer's language (English when it is none of them). The interface language is the same for every profile and does not change the practice-text language, which is chosen in Practice → Text language. See [themes and VS Code import](/en/docs/personalization/themes-and-vs-code) and [text languages](/en/docs/keyboard-and-languages/text-languages).

## Accessibility

“Screen reader announcements” and “Colour-blind mode”, both off by default. See [screen reader](/en/docs/accessibility/screen-reader) and [color-blind mode](/en/docs/accessibility/color-blind-mode).

## AI

“Use AI to generate texts”, the “Fallback chain” of up to five providers with their model and key, “Density”, the text's “Topic” and the “AI usage” table. See [turn on the AI](/en/docs/ai/turn-on-ai) and [providers and keys](/en/docs/ai/providers-and-keys).

## Profiles

The list of profiles (“Use”, “New profile”, “Rename”, “Delete”) and the active profile's “Daily goal”. See [profiles](/en/docs/progress/profiles) and [daily goal and streak](/en/docs/practice/daily-goal-and-streak).
