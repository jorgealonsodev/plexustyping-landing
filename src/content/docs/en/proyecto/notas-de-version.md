PlexusTyping's current version is 0.2.0, released on 23 November 2026, for Linux x86_64 and 64-bit Windows, with the interface in five languages and the “Unlimited” text. The app does not update itself: each new version is installed by hand. The full notes of every version are in [what's new](/en/release-notes).

## Versions

| Version | Status | Date |
|---|---|---|
| 0.2.0 | Released, current | 23 November 2026 |
| 0.1.0 | Released | 19 November 2026 |

## 0.2.0

It is distributed as `plexustyping_0.2.0_amd64.deb`, `plexustyping-0.2.0-linux-x86_64.tar.gz` and `PlexusTyping_0.2.0_x64-setup.exe`, with the `SHA256SUMS` file.

- The interface in English, Spanish, Brazilian Portuguese, French and German, which follows the computer's language (English when it is none of them) and is changed in “Settings → Appearance → Interface language”. See [text languages](/en/docs/keyboard-and-languages/text-languages).
- The text length can also be chosen in the header, next to Prose / Words / Code.
- Lengths of 800, 1000, 1500 and 2000 characters, and “Unlimited”: the text grows while you type and `Esc` or “End” scores what you typed. See [length and unlimited text](/en/docs/practice/length-and-unlimited-text).
- “Bar” is the default cursor and blinks while you are not typing. See [cursor styles](/en/docs/personalization/cursor).
- In the settings search, `Esc` clears the search from anywhere and the arrow keys on the tabs end it. See [settings search](/en/docs/settings/settings-search).
- Fixes: “Repeat” after an unlimited text repeats only what you typed, and fixes in the Linux install.

## 0.1.0

The first released version. It is distributed as `plexustyping_0.1.0_amd64.deb`, `plexustyping-0.1.0-linux-x86_64.tar.gz` and `PlexusTyping_0.1.0_x64-setup.exe`, with the `SHA256SUMS` file. It includes adaptive practice in prose, words and code, optional AI texts, the metronome, the history, profiles, 59 themes and the accessibility options this documentation describes.

## How to update

Download the new version from the [download page](/en/download). On Linux, the `.deb` is updated by installing the new one the same way as the first, and the `.tar.gz` by running `./install.sh` again from the new folder. See [update and uninstall](/en/docs/getting-started/update-and-uninstall).
