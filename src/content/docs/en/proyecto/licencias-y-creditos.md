PlexusTyping's code is released under the MIT license or the Apache-2.0 license, at your choice. The bundled material that comes from other projects keeps its own license: the fonts are OFL-1.1, the word lists CC BY-SA 4.0, the Common Voice sentences CC0 and the color themes belong to their authors. Details in [licenses](/en/licenses).

## Summary

| Material | Source | License |
|---|---|---|
| PlexusTyping code | The `jorgealonsodev/plexustyping` repository | MIT OR Apache-2.0 |
| Practice text fonts | Fontsource packages | SIL Open Font License 1.1 (OFL-1.1) |
| Word lists (es, en, pt, fr, de) | hermitdave/FrequencyWords, derived from OpenSubtitles 2018 | CC BY-SA 4.0 |
| Sentences | Mozilla Common Voice | CC0 1.0 |
| Color themes | The PlexusTerm schemes, from iTerm2-Color-Schemes and their authors | MIT (iTerm2-Color-Schemes); each theme belongs to its author |
| Code highlighting | syntect | MIT |
| Syntax definitions | two-face, curated by the bat project | MIT OR Apache-2.0; each definition keeps its license |

## Credits

- **Themes:** Catppuccin, Tokyo Night, Gruvbox, Nord, Dracula, Solarized, Rosé Pine, Everforest, Kanagawa, Ayu and the rest of the bundled schemes belong to their authors. The “PlexusTerm” palette comes from the PlexusTerm project, by the same author as PlexusTyping.
- **Fonts:** Roboto Mono, JetBrains Mono, Fira Code, Source Code Pro, IBM Plex Mono, Inconsolata, Atkinson Hyperlegible Mono, Intel One Mono, Lexend Deca and OpenDyslexic, by their respective authors.
- **Corpus:** word lists by Hermit Dave and sentences by the contributors to Mozilla Common Voice.

Each author and license is detailed in the repository's `THIRD_PARTY_NOTICES.md` file and on the [licenses](/en/licenses) page.
