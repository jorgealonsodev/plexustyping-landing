La versión actual de PlexusTyping es la 0.1.0, publicada el 19 de noviembre de 2026, para Linux x86_64 y Windows de 64 bits. La app no se actualiza sola: cada versión nueva se anuncia en las notas de versión y se instala a mano. Las notas completas de cada versión están en [Novedades](/novedades).

## Versiones

| Versión | Estado | Fecha |
|---|---|---|
| 0.1.0 | Publicada | 19 de noviembre de 2026 |
| 0.1.1 | Próxima versión | Sin fecha |

## 0.1.0

Primera versión publicada. Se distribuye como `plexustyping_0.1.0_amd64.deb`, `plexustyping-0.1.0-linux-x86_64.tar.gz` y `PlexusTyping_0.1.0_x64-setup.exe`, con el archivo `SHA256SUMS`. Incluye la práctica adaptativa en prosa, palabras y código, los textos con IA opcionales, el metrónomo, el historial, los perfiles, 59 temas y las opciones de accesibilidad que describe esta documentación.

## Próxima versión (0.1.1)

- Longitudes de texto de 800, 1000, 1500 y 2000 caracteres.
- Longitud «Ilimitado»: el texto crece mientras escribes y `Esc` o «Terminar» puntúan lo escrito. Consulta [Longitud y texto ilimitado](/docs/practicar/longitud-y-texto-ilimitado).

Hasta que se publique, estas funciones no están disponibles.

## Cómo actualizar

Descarga la versión nueva desde [Descargar](/descargar). En Linux, el `.deb` se actualiza instalando el nuevo igual que el primero, y el `.tar.gz` ejecutando otra vez `./install.sh` desde la carpeta nueva. Consulta [Actualizar y desinstalar](/docs/empezar/actualizar-y-desinstalar).
