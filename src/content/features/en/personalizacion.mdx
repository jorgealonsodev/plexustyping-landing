## 59 themes, dark and light

The 57 PlexusTerm themes plus “High contrast dark” and “High contrast light”, switched live in Settings → Appearance. The default theme is Catppuccin Mocha, the same one this website wears.

## VS Code themes

“Import VS Code theme…” reads a color theme file (`.json` or `.jsonc`, with comments, up to 1 MB) and adds it to the selector, under “Imported”. It takes the editor, cursor and selection colors and the terminal's 16 ANSI colors, which paint the keyboard and the code highlighting. Up to 30 imported themes are kept.

## Ten fonts, all bundled

Roboto Mono, JetBrains Mono, Fira Code without ligatures, Source Code Pro, IBM Plex Mono and Inconsolata to type as usual; Atkinson Hyperlegible Mono, Intel One Mono, Lexend Deca and OpenDyslexic to read better. They ship inside the app: none is downloaded from the network. You also adjust the font size (80–200 %), the letter spacing (0–0.30 em) and the line height (1.2–2.4).

## Five cursors

“Bar”, the default since 0.2.0, is a thin line between characters like Monkeytype's, with square corners. There are also “Highlight”, which tints the next character and underlines it, “Block”, “Underline” and “Outline”; on an error they take the error color. “Blinking cursor”, on by default, makes the cursor blink while you wait and stay still while you type, never with reduced motion.

## Dimmed pending text

“Dim pending text”, on by default, lowers the text you still have to type to a 2.5:1 contrast so what you typed stands out. Turning it off brings back the AA colors. High-contrast themes never dim. More options to read better under [Accessibility](/en/features/accessibility).
